📋 Detection Rules

Rule 1 — Appliance Spike: If actual consumption > expected by >20%, flag as danger anomaly.
Rule 2 — Moderate Deviation: If deviation is 10–20%, flag as warning.
Rule 3 — Daily Spike: If total daily consumption exceeds 1.5× the normal maximum (16 kWh), flag overall anomaly.
No ML used. These simple rules are easy to explain in a viva. The algorithm runs entirely in JavaScript.
