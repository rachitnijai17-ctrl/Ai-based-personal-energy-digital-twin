📋 How Prediction Works

This system uses a Moving Average + Trend Adjustment method:
1. Average the last 3 months of consumption.
2. Calculate the trend (difference between last two months).
3. Predicted = Average + (Trend × 0.5).
4. Confidence is based on variation in the last 3 months.

This is a simple, explainable method — no machine learning involved.
